# Thomas Derouck Academic Website

Static academic profile and curriculum vitae website.

## Preview locally

Open `index.html` in a web browser. No server or build step is required.

## Main pages

- `index.html` — Profile, research overview, expertise, and interests
- `experience.html` — Research experience, teaching, science communication, supervision, and academic service
- `research.html` — Current, collaborative, and previous research projects
- `publications.html` — Publications, preprints, selected presentations, and collaborative contributions
- `awards.html` — Funding, awards, and distinctions
- `cv.html` — Academic CV overview
- `contact.html` — Contact form and professional profiles

The legacy `about.html` and `teaching.html` URLs redirect to `experience.html`.

## Shared assets

- `style.css` — Global styles, themes, responsive layout, and print rules
- `components.js` — Shared navigation, footer, theme control, and page effects
- `profile.jpg` — Profile photograph
- `favicon.ico` — Browser icon

The downloadable PDF version of the CV will be prepared separately.
